# Reference fixtures

Canonical public DSL and IR fixtures used by NemoIR tests, docs, and examples.

- `coding-agent.nemo` + `coding-agent-ir.yml`: multi-stage coding workflow with policies.
- `judge_candidate.nemo` + `judge_candidate-ir.yml`: numeric guard and transition-order golden pair.
- `hint_tutor.nemo` + `hint_tutor-ir.yml`: browser-safe tutoring workflow golden pair.
- `policy_command_allowlist.nemo`: policy-expression reference fixture without a checked-in IR snapshot.

These files are the canonical copies for the promoted public fixtures.
